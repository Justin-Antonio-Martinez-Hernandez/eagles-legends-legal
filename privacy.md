# Política de Privacidad – Eagles Legends Rich Presence

**Última actualización:** 7 de noviembre de 2026

## 1. Introducción

Eagles Legends Rich Presence es una aplicación independiente para Windows que permite a los usuarios mostrar actividades personalizadas relacionadas con la comunidad Eagles Legends en Discord.

Respetamos la privacidad de nuestros usuarios y buscamos utilizar únicamente la información necesaria para proporcionar las funciones de la aplicación.

## 2. Información que utiliza la aplicación

La aplicación puede utilizar la siguiente información:

- La actividad seleccionada por el usuario, como Scrim, Torneo o Entrenamiento.
- El tiempo transcurrido desde que se inició la actividad.
- El estado de conexión con el cliente de Discord.

Esta información se utiliza para mostrar la actividad seleccionada mediante la integración de Discord.

## 3. Recopilación y almacenamiento

La aplicación no solicita contraseñas, tokens de Discord, documentos personales ni datos de pago.

En su funcionamiento previsto, no dispone de cuentas propias ni de una base de datos centralizada para almacenar información personal de los usuarios.

## 4. Integración con Discord

Eagles Legends Rich Presence utiliza las funciones de integración de Discord para mostrar la actividad seleccionada por el usuario.

Discord puede procesar información de actividad conforme a sus propias políticas y condiciones.

Consulta la política de privacidad de Discord:

https://discord.com/privacy

## 5. Compartición de información

Eagles Legends no vende información personal de los usuarios.

La actividad que el usuario decida mostrar puede ser visible para otras personas en Discord, dependiendo de su configuración de privacidad y estado.

## 6. Seguridad

Recomendamos descargar la aplicación únicamente desde fuentes oficiales proporcionadas por el equipo de Eagles Legends.

Nunca compartas contraseñas, tokens o credenciales de tu cuenta de Discord.

## 7. Cambios en esta política

Esta política puede actualizarse cuando se incorporen nuevas funciones o cambie el funcionamiento de la aplicación.

## 8. Contacto

Para preguntas, solicitudes o dudas relacionadas con la privacidad, puedes contactar con el equipo de Eagles Legends mediante su servidor oficial de Discord.
